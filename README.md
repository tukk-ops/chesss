# ♟️ 西洋棋：多功能對戰版 (Chess App)

這是一個用 Python 寫的西洋棋遊戲，不需要安裝任何奇奇怪怪的套件，下載下來就能直接玩！支援**雙人對打**與**人機對戰**，還包含了完整的規則判定（如兵種升變、不能自殺的合法走法、將死判定等），非常適合當作期末專案或學弟妹的學習範例。

---

## 🛠️ 電腦環境準備

這個專案只用到 Python 的內建功能（tkinter畫面庫），所以完全不用安裝額外的軟體套件。

## 🎮 遊戲怎麼玩？

1. **切換模式**：右邊面板可以隨時切換「玩家 vs AI」或「玩家 vs 玩家」。切換時遊戲會自動重新開始。
2. **選取棋子**：用滑鼠左鍵點擊你的棋子，選中後棋子會出現**黃色框框**，同時棋盤上會出現**灰色圓點**，告訴你這顆棋子可以走到哪裡。
3. **移動與吃子**：點擊灰色圓點，棋子就會走過去。如果格子上有敵方棋子，就會自動把它吃掉。
4. **特殊規則（兵種升變）**：當你的「兵 (Pawn)」一路衝到最底線時，畫面會彈出一個小視窗，讓你想變身成皇后、城堡、主教還是騎士，點一下就能完成變身！
5. **勝負判定**：當某一邊被「將死」或者走到「逼和（沒有任何路可以走）」時，系統會跳出大大的提示視窗宣告遊戲結束。
=================================================================================================================1. main.py (主程式與 GUI 層)
負責遊戲的圖形介面渲染、使用者互動處理以及遊戲主流程控制。

介面初始化 (ChessApp.__init__)：建立 tkinter 視窗、畫布 (Canvas) 以及側邊控制面板（模式選擇、回合提示、重新開始按鈕）。
棋盤渲染 (render)：繪製 8x8 棋盤交錯網格、棋子符號，以及選中棋子時的高亮顯示與合法移動提示點。
事件驅動 (handle_click)：捕捉滑鼠點擊事件。負責判斷是「選中己方棋子」還是「移動至目標點」，並包含兵的升變 (Promotion) 觸發邏輯。
兵的升變 (promote_pawn)：彈出對話框讓玩家選擇要升變的棋子（后、車、象、馬），並替換原來的兵。
遊戲流程控制 (end_turn, check_end_game)：切換回合，檢查是否有合法步數。若無合法步，則結合 logic.py 判斷是「將死 (Checkmate)」或「逼和 (Stalemate)」。
AI 整合 (execute_ai_move)：若為 PVE 模式且輪到黑方，則延遲 600 毫秒後呼叫 ai.py 進行操作。
2. pieces.py (棋子實體與移動規則)
定義所有棋子的基礎屬性與「偽合法步 (Pseudo-legal moves)」生成邏輯（尚未考慮是否被將軍）。

基礎類別 Piece：紀錄棋子顏色、座標 (x, y)。提供邊界檢查 is_on_board 與目標格子狀態檢查 check_cell_status (0: 空, 1: 己方, 2: 敵方)。
特殊步長類別：
Pawn：負責處理兵的單步前進、首步雙步前進以及斜向吃子（未實作吃過路兵 En Passant）。
Knight：處理馬的 L 型跳躍（共 8 個方向）。
King：處理國王的 8 向單步移動（未實作王車易位 Castling）。
滑動棋子類別 SlidingPiece：
Rook (車)、Bishop (象)、Queen (后) 繼承此類，使用 get_sliding_moves 往特定方向無限延伸，直到遇到邊界或阻擋物。
3. logic.py (核心遊戲規則判斷)
負責處理西洋棋最關鍵的「將軍 (Check)」與「絕對合法步」驗證。

is_in_check(color, piece_list)： 尋找指定顏色的國王，並檢查對手所有的偽合法步中，是否包含了該國王所在的座標。若是，回傳 True。
get_legal_moves(piece, piece_list)： 取得棋子的偽合法步後，逐一「模擬」這些移動。在每次模擬移動後，呼叫 is_in_check 檢查自己是否處於被將軍狀態。如果不處於被將軍狀態，這一步才是真正的合法步。此機制防止了玩家走出讓自己被將軍的送死步。
4. ai.py (人工智慧決策)
一個針對黑方的簡易 Greedy (貪婪) 演算法 AI，搜尋深度為 1-ply（僅看下一步）。

evaluate_board(piece_list)： 透過 constants.py 的權重分數來計算盤面總分。黑方子力加分，白方子力扣分。
ai_make_move(piece_list)：
收集所有黑棋當前的絕對合法步。
隨機打亂這些步數 (random.shuffle)，防止在多個相同分數的最佳步中總是走同一路徑，增加變化性。
逐一模擬這些合法步，並呼叫 evaluate_board 給分。
記錄並回傳能讓盤面分數（黑方優勢）最大化的一步。
5. constants.py (常數配置)
集中管理遊戲中使用的靜態資料，方便全域修改。

SYMBOLS：定義各棋子對應的 Unicode 符號，用於 GUI 顯示。
PIECE_VALUES：定義各棋子的 AI 評分權重（例如 Pawn: 10, Queen: 90, King: 900）。
LIGHT_COLOR / DARK_COLOR：定義棋盤黑白格的 Hex 色碼。

6.改進空間
uiux的使用者介面，這種輔助介面，有多元的語言可供選擇
演算法，也是有更多元選擇，單依賴貪婪過於偏激，且在部分時刻，會沒感覺笨笨的。
